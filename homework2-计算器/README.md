# homework2-计算器（实验1：带键盘事件的计算器）

Qt 应用程序开发课程 实验一 —— 桌面计算器，鼠标点击与键盘输入均可完成计算。

## 键盘按键对照表（第三次提交新增）

| 键盘 | 功能 | 键盘 | 功能 |
|---|---|---|---|
| `0`~`9`（主键盘/小键盘） | 数字输入 | `Backspace` | 退格 ⌫ |
| `.` 或 `,` | 小数点 | `Delete` | 相当于 `C`（只清当前输入） |
| `+` `-` `*` `x` `/` | 四则运算（`*` `x` 都表示乘） | `Esc` | 相当于 `CE`（清空整个计算） |
| `Enter` `Return` `=` | 等于 | `%` | 百分号 |
| `@` | 开平方 `√` | `q` | 平方 `x^2` |
| `r` | 倒数 `1/x` | `F9` | 正负号 `±` |

鼠标与键盘调用的是同一套处理函数，因此两种输入方式的结果完全一致，也可以混合使用
（例如先点 `6`、按 `*`、再点 `7`、按回车）。

## 已实现功能

**运算**

- 四则运算 `+` `-` `×` `/`，含优先级：`1 + 2 × 3 =` 得到 `7`
- 连续运算与结果复用：`1 + 2 + 3 =` 得到 `6`；`2 + 3 =` 后接着 `× 4 =` 得到 `20`
- 单目运算：`±` 正负号、`√` 开平方、`x^2` 平方、`1/x` 倒数、`%` 百分号
  （`%` 与常用计算器一致：`50 + 10 % =` 得到 `55`，`50 × 10 % =` 得到 `5`）

**输入与编辑（鼠标 + 键盘）**

- 数字 `0~9`，自动去掉前导零（连续按 0 不会出现 `000`）
- 小数点 `.`：同一个操作数内只允许一个小数点，重复按被忽略
- 退格 `⌫`、`C`（只清当前输入的数）、`CE`（清空整个计算）

**异常与边界**

- 除数为 0：显示"除数不能为0"，进入错误状态，下一次输入自动清零重新开始
- `1/x` 对 0、`√` 对负数：显示"除数不能为0" / "负数不能开平方"
- 连按运算符（如 `8 + × 2 =`）：新运算符自动替换旧运算符，得到 `16`
- 结果后直接按数字：开始新一次计算；结果后按运算符：结果继续参与运算
- 计算中按 `=` 两次：显示保持不变，不会重复累加

## 关键实现说明

- 状态：`operand`（当前输入/显示的数值串）+ `operands`（操作数栈）+ `opcodes`（运算符栈），
  配合 `operandEntered`（当前是否是一个待参与运算的操作数）、`hasResult`（刚算完结果）、
  `errorState`（错误提示状态）三个状态位描述整个计算过程
- `keyPressEvent()`：把键盘按键翻译成与鼠标相同的调用——`appendDigit()`（数字/小数点）、
  `applyBinaryOperator()`（四则运算）、`applyUnary()`（单目运算）、`on_btnEqual_clicked()`（等于）等，
  鼠标按钮的槽函数也只做"取按钮文字 → 交给同一个函数"，两种输入方式不存在两套逻辑
- 显示区 `display` 设为只读并取消焦点（`Qt::NoFocus`），否则点击显示区后键盘输入会被 `QLineEdit` 吃掉
- `calculation(bool *ok)`：结算栈顶的一次二元运算（弹出两个操作数和一个运算符），
  通过 `ok` 告诉调用方是否真的算过，避免把显示刷成 0
- `priority(opcode)`：`×` `/` 优先级高于 `+` `-`；按运算符时先把栈顶优先级不低于新运算符的运算结算掉，
  因此连续输入也能得到正确结果
- 结果统一用 `formatNumber()`（`QString::number(value,'g',12)`）格式化，避免 `0.1+0.2` 显示成一长串浮点数
- 运算符文字取自按钮 `text()`，与 `.ui` 保持一致：加法键是 `btnAdd`，`×` 为 U+00D7，`±` 键是 `btnPlus`

## 编译与运行

需要 Qt 6（开发环境：Qt 6.11.2 MinGW 64-bit）。

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug -DCMAKE_PREFIX_PATH=<Qt安装目录>/6.11.2/mingw_64
cmake --build build
./build/Lab1.exe
```

也可以直接用 Qt Creator 打开 `CMakeLists.txt` 后运行。
