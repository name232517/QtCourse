# homework2-计算器（实验1：带键盘事件的计算器）

Qt 应用程序开发课程 实验一 —— 桌面计算器，鼠标点击与键盘输入均可完成计算。

## 键盘按键对照表

| 键盘 | 功能 | 键盘 | 功能 |
|---|---|---|---|
| `0`~`9`（主键盘/小键盘） | 数字输入 | `Backspace` | 退格 ⌫ |
| `.` 或 `,` | 小数点 | `Delete` | 相当于 `C`（只清当前输入） |
| `+` `-` `*` `x` `/` | 四则运算（`*` `x` 都表示乘） | `Esc` | 相当于 `CE`（清空整个计算） |
| `Enter` `Return` `=` | 等于 | `%` | 百分号 |
| `@` | 开平方 `√` | `q` | 平方 `x^2` |
| `r` | 倒数 `1/x` | `F9` | 正负号 `±` |

鼠标与键盘调用的是同一套处理函数，因此两种输入方式的结果完全一致，也可以混合使用。

## 已实现功能

**运算**

- 四则运算 `+` `-` `×` `/`，含优先级：`1 + 2 × 3 =` 得到 `7`
- 连续运算与结果复用：`1 + 2 + 3 =` 得到 `6`；`2 + 3 =` 后接着 `× 4 =` 得到 `20`
- 单目运算：`±` 正负号、`√` 开平方、`x^2` 平方、`1/x` 倒数、`%` 百分号
  （`%` 与常用计算器一致：`50 + 10 % =` 得到 `55`，`100 + 10 % =` 得到 `110`）

**输入与编辑（鼠标 + 键盘）**

- 数字 `0~9`，自动去掉前导零；超过 16 位有效数字后忽略多余按键
- 小数点 `.`：同一个操作数内只允许一个小数点，重复按被忽略
- 退格 `⌫`、`C`（只清当前输入的数）、`CE`（清空整个计算）

**异常与边界（第四次提交重点）**

- 除数为 0、对 0 求倒数、对负数开平方：显示提示信息并进入错误状态，下一次输入自动清零
- 连续运算符（`8 + × 2 =` → 16）：新运算符自动替换旧运算符
- 末尾悬挂运算符（`1 + 2 × =` → 3、`1 + =` → 1）：按 `=` 时丢弃没有第二个操作数的运算符
- 计算结果后继续输入：按数字开始新计算、按运算符用结果继续算、按退格归零、按小数点得到 `0.`
- 退格到空再输入、清除后重新计算、鼠标与键盘混合输入，均与"从零开始输入"行为一致

## 边界与异常处理记录（第四次提交）

| 测试输入 | 原程序现象 | 原因分析 | 修改方法 | 修改后结果 |
|---|---|---|---|---|
| `1 ÷ 3 × 3 =`（连续运算） | 显示 `0.999999999999` | 中间结果存进操作数栈时被格式化成 12 位有效数字，再次参与运算时精度已经丢失 | 运算链内部改用 `storeNumber()`（17 位有效数字，double 往返精度）保存，只在显示时用 `formatNumber()`（12 位）格式化 | 显示 `1` |
| `1 ÷ 3 = × 3 =`（结果复用） | 显示 `0.999999999999` | 同上：`=` 之后操作数被截断，再参与运算时精度丢失 | 同上（`=` 的结果也按 17 位保存） | 显示 `1` |
| `1 + 2 × =`（末尾悬挂运算符） | 显示 `2` | 按 `=` 结算时把末尾没有第二个操作数的 `×` 也当作有效运算符，用 `1 × 2` 计算 | 按 `=` 时先判断运算符个数是否不少于操作数个数，是则丢弃末尾悬挂的运算符 | 显示 `3` |
| 连续输入 17 位数字 | 显示 17 位数字，但继续运算时数值已与显示不符 | 超过 double 精度后无法精确表示 | 输入超过 16 位有效数字时忽略多余按键 | 显示 `1234567890123456` |
| `5 ÷ 0 =`（除零） | —— | —— | 弹出提示"除数不能为0"，进入错误状态；下一次输入自动清零 | 显示 `除数不能为0`，按 `7` 后显示 `7` |
| `1 . 2 . 3`（连续小数点） | —— | —— | 同一操作数内已存在小数点则忽略 | 显示 `1.23` |
| `12 + 34 ⌫ ⌫`（退格到空） | —— | —— | 退到空显示 `0`，下一个数字重新开始输入 | 显示 `0`，接 `=` 得 `12` |
| `1 + 2 C 3 =`（C 与 CE 的区别） | —— | —— | `C` 只清当前输入的数、保留挂起的运算，`CE` 清空整个计算 | `4`；`CE` 版本为 `3` |
| `8 + × 2 =`（连按运算符） | —— | —— | 新运算符替换旧运算符 | `16` |
| `9 ± √ + 4 =`（负数开平方后继续算） | —— | —— | 错误状态在下一次输入时自动清零 | `4` |

## 关键实现说明

- 状态：`operand`（当前输入/显示的数值串）+ `operands`（操作数栈）+ `opcodes`（运算符栈），
  配合 `operandEntered`（当前是否是一个待参与运算的操作数）、`hasResult`（刚算完结果）、
  `errorState`（错误提示状态）、`typingDigits`（是否正在逐位输入）描述整个计算过程
- 精度：`storeNumber()`（17 位有效数字）用于继续运算，`formatNumber()`（12 位）只用于显示，
  显示区在逐位输入时原样显示，避免出现 `0.1+0.2` 或 `1÷3×3` 的浮点误差
- `calculation(bool *ok)`：结算栈顶的一次二元运算（弹出两个操作数和一个运算符），
  通过 `ok` 告诉调用方是否真的算过，避免把显示刷成 0
- `priority(opcode)`：`×` `/` 优先级高于 `+` `-`；按运算符时先把栈顶优先级不低于新运算符的运算结算掉
- `keyPressEvent()`：键盘按键翻译成与鼠标相同的调用（`appendDigit()` / `applyBinaryOperator()` /
  `applyUnary()` / `on_btnEqual_clicked()`），两种输入方式共用一套逻辑
- 显示区 `display` 设为只读并取消焦点（`Qt::NoFocus`），否则键盘输入会被 `QLineEdit` 吃掉
- 运算符文字取自按钮 `text()`，与 `.ui` 保持一致：加法键是 `btnAdd`，`×` 为 U+00D7，`±` 键是 `btnPlus`

## 编译与运行

需要 Qt 6（开发环境：Qt 6.11.2 MinGW 64-bit）。

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug -DCMAKE_PREFIX_PATH=<Qt安装目录>/6.11.2/mingw_64
cmake --build build
./build/Lab1.exe
```

也可以直接用 Qt Creator 打开 `CMakeLists.txt` 后运行。

### 边界与异常用例（37 条）

- 精度：`1/3*3=`→1、`2/3*3=`→2、`1/3=*3=`→1、`0.1+0.2=`→0.3

- 除零：`5/0=+2=`→2、`6/0*22`→22、`1+6/0=`→除数不能为0
- 前导零与小数点：`000`→0、`...`→0.、`1..5`→1.5、`0.5+0.5=`→1
- 结果后继续输入：`2+3=.`→0.、`2+3=<`→0、`2+3=+3=`→8、`2+3=*3=`→15、`1+2=4=`→4
- 退格：`123<<<`→0、`12+34<<`→0、`12+3<=`→12

- 单目运算边界：`9±√+4=`→4、`0x^2`→0、`0√`→0、`5±±`→5、`100+10%=`→110、
  `3-5=√`→负数不能开平方、`3-5=x^2`→4
