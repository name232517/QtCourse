# homework2-计算器（实验1：带键盘事件的计算器）

Qt 应用程序开发课程 实验一 —— 桌面计算器。

## 已实现功能

- 数字 `0~9` 输入，自动处理前导零（连续按 0 不会出现 `000`）
- 小数点 `.`：同一个操作数内不允许重复输入小数点
- 退格 `⌫`、清除 `C`
- 四则运算 `+` `-` `×` `/`，支持连续运算（结果会回填到操作数栈）
- 除数为 0 时返回 0，不会崩溃
- 按运算符后显示不会被子虚乌有的 `0` 覆盖（只有真正算完才刷新显示）

## 关键实现说明

- 状态：`operand`（当前正在输入的数字串）、`operands`（操作数栈）、`opcodes`（运算符栈）
- `calculation(bool *ok)`：当 `operands.size() >= 2 && opcodes.size() >= 1` 时弹出两个操作数和一个运算符完成一次计算，并通过 `ok` 告诉调用方"这次是真的算过了"，避免在算不出来时把显示刷成 0
- 运算符文字取自按钮 `text()`，与 `.ui` 保持一致：`+` 键为 `btnAdd`，`×` 为 U+00D7，`±` 键是 `btnPlus`（正负号）

## 编译与运行

需要 Qt 6（开发环境：Qt 6.11.2 MinGW 64-bit）。

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug -DCMAKE_PREFIX_PATH=<Qt安装目录>/6.11.2/mingw_64
cmake --build build
./build/Lab1.exe
```

也可以直接用 Qt Creator 打开 `CMakeLists.txt` 后运行。
